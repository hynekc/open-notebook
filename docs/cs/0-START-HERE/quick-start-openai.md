# Rychlý start – OpenAI

Tento návod byl sloučen do **[Rychlého startu s cloudovým poskytovatelem](quick-start-cloud.md)**, který stejnými kroky pokrývá OpenAI i všechny ostatní cloudové poskytovatele.

U OpenAI při připojování poskytovatele zvolte **OpenAI** a přidejte jeden model typu **Language** a jeden typu **Embedding** (například `text-embedding-3-small`). OpenAI nabízí i modely převodu textu na řeč a řeči na text pro podcasty a zvukové zdroje.
